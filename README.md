# HandyGod

**HandyGod** is a 2D physics-based platformer built in Unity. In this game, the player simultaneously controls two entities:  
1. A stickman (using keyboard controls)  
2. A floating hand (using the mouse)  

The hand can grab and manipulate objects, ropes, bridges, or obstacles to help the stickman advance and create new paths.  

---

## 🎮 Gameplay & Concept

- You move the stickman using **W / A / S / D** (or arrow keys) and **Space** to jump.  
- You control the **floating hand** with your mouse cursor. The hand can grab certain objects (bridges, ropes, levers, blocks) and manipulate them—pull, drag, move them—to open up routes for the stickman.  
- The core mechanic is coordinating both characters: use the hand to adjust the environment in real time as the stickman moves through the level.  
- Because of physics, objects react realistically: swinging ropes, rotating bridges, falling blocks, etc.
